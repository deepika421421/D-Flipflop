# D Flip-Flop in Verilog

## Description

This project implements a positive-edge triggered D Flip-Flop using Verilog HDL.

A D Flip-Flop stores one bit of data and updates its output on the rising edge
of the clock.

The design also includes an active-high synchronous reset.
